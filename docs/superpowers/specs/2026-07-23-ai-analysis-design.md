# FreelanceTrust Audit — AI-анализ

## Цель

Дополнить существующий локальный аудит Kwork-профиля бесплатным AI-анализом без передачи API-ключа в браузер. Сайт остаётся полезным без настроенного ключа.

## Архитектура

Vite продолжает обслуживать React-интерфейс. Небольшой Express-сервер предоставляет единственный `POST /api/analyze`, загружает `.env` только на сервере и проксируется Vite в разработке. Он принимает ограниченный `ProfileInput`, выполняет локальный scoring, затем при наличии ключа вызывает Responses API с моделью из `OPENAI_MODEL` или `gpt-5.6-luna`.

## Гибридный отчёт

Локальный scorer всегда рассчитывает балл, доверие и вероятность заказа. AI возвращает только улучшенные текстовые части: краткое резюме, барьер, проблемы, рекомендации, пять взглядов клиента и контент «до / после». Сервер валидирует все обязательные поля. При отсутствии ключа, ошибке запроса или неполном JSON возвращается локальный отчёт с режимом `basic` и объяснением причины. UI использует одну модель отчёта независимо от режима.

## Защита расходов и данных

Сервер отбрасывает полностью пустой профиль и обрезает каждое текстовое поле до заданного лимита, а весь запрос — до безопасного бюджета. Один submit создаёт один запрос; повторный запуск отключён во время ожидания. Ключ не включается в Vite-переменные и не возвращается клиенту.

## Файлы

- `.env.example`, `.gitignore` — безопасная настройка окружения.
- `server/index.ts` — endpoint, лимиты и fallback.
- `server/prompt.ts`, `server/schema.ts` — system prompt и JSON Schema/валидация.
- `src/api/analyze.ts` — браузерный запрос к endpoint.
- `src/domain/profile.ts` — расширенный тип отчёта с режимом и AI-полями.
- `src/App.tsx`, `src/components/Dashboard.tsx`, `src/styles.css` — статусы и результат.
- `README.md` — запуск и API-настройка.

## Проверка

Unit-тесты проверяют ограничение полей, валидацию AI-ответа и fallback. Проверяются `npm test -- --run`, `npm run lint`, `npm run build`, затем запускается `npm run dev`.
