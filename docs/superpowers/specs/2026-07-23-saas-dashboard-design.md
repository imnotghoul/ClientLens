# FreelanceTrust Audit — SaaS dashboard

## Цель

Развить MVP в полноценный бесплатный SaaS-интерфейс: тёмный продуктовый dashboard, локальная история, три режима анализа и три управляемые модели OpenAI.

## Навигация и состояние

Приложение становится SPA с разделами «Новый анализ», «Мои отчёты», «Демо-анализ», «История», «Профиль» и «Настройки». Данные отчётов, активный раздел, тема и выбор модели хранятся в `localStorage`; API-ключ никогда не хранится в браузере.

## Режимы

- `quick` — общий score, главный риск, три проблемы и три быстрые правки.
- `deep` — полный отчёт с 12 категориями, клиентскими перспективами и улучшениями.
- `competitive` — ручной ввод до трёх конкурентов и сравнение с профилем пользователя.

## Модели OpenAI

Пользователь выбирает только уровень анализа, а сервер сопоставляет его с допустимой моделью: `gpt-5.6-luna` (по умолчанию, экономичный), `gpt-5.6-terra` (сбалансированный), `gpt-5.6-sol` (максимально глубокий). Сервер использует этот выбор только при наличии ключа; при ошибке или отсутствии ключа продолжает работать локальный fallback. Модель из `OPENAI_MODEL` остаётся серверным дефолтом для Luna.

## Дизайн

Почти чёрный фон, фиолетовый акцент, прозрачные панели, тонкий glow и плотная сетка информации. Результат строится вокруг trust score, category map, рекомендаций и клиентских вкладок. На мобильных устройствах sidebar превращается в компактную нижнюю/верхнюю навигацию, а grids становятся одноколоночными.

## Архитектура

Компоненты UI не считают баллы. Отдельные модули отвечают за режимы анализа, преобразование локального отчёта, AI-подсказки, демо-данные и local report storage. Существующие `PlatformAnalyzer`, `KworkAnalyzer`, local scorer и AI endpoint сохраняются и расширяются.

## Проверка

Покрыть тестами выбор режима, local report storage и fallback. Проверить быстрый, глубокий, конкурентный и демо-сценарии с ключом и без него, затем lint, build и адаптивные брейкпоинты.
