# ClientLens AI Relay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Route ClientLens AI analysis through a protected Render relay while preserving the VPS fallback.

**Architecture:** Add a standalone `relay` Node service in the existing repository. The VPS API calls it with `AI_RELAY_SECRET`; the relay calls OpenRouter with `OPENROUTER_API_KEY` and returns the same AI payload.

**Tech Stack:** Node.js, TypeScript, Express, Vitest, Render Web Service, OpenRouter API.

## Global Constraints

- Never expose OpenRouter or relay secrets to the browser.
- Keep local scoring as a fallback.
- Do not persist profile data in the relay.
- Limit relay input to 24 KB and requests to 30 per minute per IP.
